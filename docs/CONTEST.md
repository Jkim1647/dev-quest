## DEV QUEST 출품 적합성

DEV QUEST는 Zaemit과 MCP를 이용해 기획, 정보 구조, UI, 데이터 저장, 공개 API, 반응형 접근성, SEO 설정과 배포 검증까지 수행한 실제 운영형 웹사이트입니다. 단순한 시각 시안이 아니라 학습 기록과 방명록 데이터가 지속적으로 축적되는 구조라는 점을 핵심 차별점으로 제시합니다.

## 제출 전 체크리스트

- [x] Zaemit으로 사이트 제작
- [x] Zaemit MCP를 실제 제작 과정에 활용
- [x] 공개 URL 발행 및 비로그인 접근 확인
- [x] 작품명, 목적, 대상 사용자, 이용 방법 작성

- [x] 허위 경력·수치·성과 없이 실제 상태만 표시
- [x] 2차 디자인 완성도 및 콘텐츠 밀도 개선
- [ ] 데스크톱·태블릿·모바일 최종 캡처 보관

## 심사 전달 포인트

1. RPG 세계관을 개발 성장 과정에 일관되게 적용한 정보 설계
2. Algorithm, AI, Project를 하나의 World Map으로 연결한 탐색 경험
3. Zaemit MCP를 콘텐츠 수정뿐 아니라 데이터 시트, API, SEO, QA에 활용
4. 실제 기록이 쌓일수록 확장되는 공모전 이후의 운영 가능성
5. 빈 데이터와 미확정 성과를 꾸며내지 않는 신뢰 중심 포트폴리오

- 실제 모바일 기기에서 최종 스크롤 감각 확인
- 실제 GitHub, Email, Blog 주소가 준비되면 연결
- 실제 학습 기록과 Achievement 근거 등록
- 방명록 메시지 공개 승인 운영 절차 확인
- 임시 주소의 Description, robots, OG image 문제를 관리자 지원 또는 사용자 도메인에서 재확인
- Google Forms 최종 제출
