# Contest submission copy

## 작품명

DEV QUEST

## 슬로건

Build. Solve. Learn. Repeat.

## 목적

알고리즘, AI 학습, 프로젝트 경험을 RPG의 Quest와 성장 시스템처럼 기록하고 시각화하는 개인 개발 성장 아카이브입니다. 개발 과정과 성취를 꾸준히 축적해 취업 포트폴리오, 개인 홈페이지, 학습 기록 공간으로 활용하는 것이 목적입니다.

## 대상 사용자

개발자의 성장 과정과 역량을 확인하려는 채용 담당자와 현업 개발자, 학습 기록을 참고하려는 개발 입문자와 동료 학습자, 프로젝트 협업을 검토하는 관계자를 대상으로 합니다. 운영자 본인이 학습 과정과 목표를 관리하는 공간이기도 합니다.

## 이용 방법

메인 화면에서 현재 학습 목표와 성장 상태를 확인하고 World Map을 통해 관심 영역으로 이동합니다. Algorithm Dungeon에서는 문제 풀이와 회고를, AI Laboratory에서는 AI 개념과 실험 기록을, Project City에서는 프로젝트의 문제·구현·성과를 살펴볼 수 있습니다. Journey와 Achievements에서 성장 과정과 달성 기록을 확인하고 Guestbook에서 피드백을 남길 수 있습니다.

## 향후 이용 계획

DEV QUEST를 알고리즘 문제 풀이, AI 학습, 개발 프로젝트 경험을 지속적으로 축적하는 개인 개발 성장 아카이브로 운영할 계획입니다. Zaemit의 데이터 시트와 CMS 기능을 활용해 기록을 꾸준히 추가하고 실제 성취가 생길 때마다 Quest, Journey, Achievement를 업데이트하겠습니다. 방명록을 통해 방문자의 피드백을 수집하며 취업 포트폴리오와 개인 홈페이지로 장기간 활용할 예정입니다.
